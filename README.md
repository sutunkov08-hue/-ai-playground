# Ragdoll Lab

Прототип игры-песочницы в стиле **People Playground**: физический рэгдолл, оружие,
взрывчатка, огонь, кровь и декали — всё в одном файле.

## Запуск

1. Сохраните/склонируйте репозиторий.
2. Откройте `index.html` в любом современном браузере — установка и локальный сервер не нужны.
   (Нужен только интернет для загрузки Matter.js с CDN.)

## Управление

| Действие | Клавиши |
|---|---|
| Схватить / перетащить объект | ЛКМ |
| Спавн выбранного объекта | ЛКМ по пустому месту |
| Спавн с поворотом | Q / E |
| Использовать объект (огонь, детонация) | F (удерживайте для автоматического огня) |
| Перемещение камеры | Стрелки, ПКМ (тащить), W/S — по вертикали |
| Вращать объект в руке | A / D (пока держите ЛКМ) |
| Зум | Колесо мыши |
| Замедление времени | Space |
| Пауза | P |
| Удалить объект | Del / Backspace |
| Меню объекта (заморозка, поджог, удаление) | ПКМ по объекту |
| Отмена выбора | Esc |

## Возможности

- Рэгдолл из 13 частей тела с ограничениями углов в суставах, мышечным тонусом,
  ходьбой, паникой от боли, уронами, нокаутом и отрывом конечностей; кровотечение и кровавые декали.
- Пистолет и автомат (физические пули с трассерами, отдача, вспышки).
- Меч и бита (ударный урон с учётом скорости замаха).
- Бочка с топливом и C4: детонация от удара, клавиши F, огня или по цепочке;
  ударная волна, обжигающие декали, экранная тряска.
- Металлический ящик, деревянная доска (горит), батут.
- Инструменты «Верёвка» и «Сварка» — соединение любых двух объектов.
- Огонь распространяется при касании, обугливает тела.
- Синтезированные звуки через Web Audio API, без внешних ресурсов.
